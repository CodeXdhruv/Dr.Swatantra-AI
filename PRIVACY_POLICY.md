## 1. Information We Collect

### 1.1 Personal Information You Provide

When you create an account or use our services, we may collect:

- **Name and Email Address:** When you sign up using Google Sign-In or email/password authentication
- **Phone Number:** Optional contact information you provide during profile setup
- **Profile Information:** Display name, profile picture (if provided through Google)
- **User-Generated Content:** 
  - Daily journal entries
  - Wellness goals and habit tracking data
  - Chat messages with the AI assistant
  - Voice recordings (when using voice assistant feature)

### 1.2 Automatically Collected Information

When you use our app, we automatically collect:

- **Device Information:** Device model, operating system version, unique device identifiers
- **Usage Data:** Features used, time spent in app, interaction patterns
- **Performance Data:** App crashes, errors, and technical diagnostics (via Firebase Crashlytics)
- **Network Information:** Internet connection status (to ensure proper app functionality)

### 1.3 Voice Data

When you use the voice assistant feature:
- **Voice Recordings:** Temporarily processed for speech-to-text conversion
- **Audio Processing:** Voice data is processed in real-time and NOT permanently stored on our servers
- **Transcriptions:** Text transcriptions of your voice queries are used to provide AI responses

**Important:** We do NOT store your actual voice recordings. Only text transcriptions are retained for improving AI responses.

## 4. Data Security

We take security seriously and implement industry-standard measures:

### 4.1 Technical Safeguards
- **Encryption in Transit:** All data is transmitted over HTTPS (TLS 1.2+)
- **Encryption at Rest:** Firebase stores data with encryption
- **Secure Authentication:** OAuth 2.0 for Google Sign-In
- **Network Security:** No cleartext HTTP traffic allowed

### 4.2 Access Controls
- **Limited Access:** Only authorized personnel can access user data
- **Secure Storage:** API keys and credentials stored in secure environment variables
- **Regular Audits:** Periodic security reviews and vulnerability assessments

### 4.3 Data Retention
- **Active Accounts:** Data retained while your account is active
- **Account Deletion:** Upon request, we delete your data within 30 days
- **Backup Data:** Backup copies automatically deleted after 90 days

**Note:** No security system is 100% foolproof. While we strive to protect your data, we cannot guarantee absolute security.
